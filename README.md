**This is glBlocksMinesCraft**

A graphics application simulating a custom voxel engine using purely the power of C++ in OpenGL.
- This application can generate chunks of natural blocks like grass, stone, vegetation like trees, grass, flowers, and ores like iron and diamond.
- Caves are also present, generated by precomputted noise maps and distinguishing by height levels all the way to the base level distinguished by an indestructible bedrock
- In addition to these, phong lighting(using directional and point lights on torches) and directional shadow mapping are performed using the OpenGL API to add more details to the world.
- Efficient face, chunk and block culling was also performed in order to maximize the speed of chunk generation and reduce lag.
- Stepwise block breaking using tools like pickaxes and axes with item drop alongside moddable tool attributes like speed and affinity
- Third person mode(In progress)
- Bounding Sphere Frustum Culling is also implemented enabling stable FPS(60-144) with a rendering distance of upto 32 chunks of 16x16x356 blocks
