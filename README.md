**This is glBlocksMinesCraft**

A graphics application capable of simulating a voxel engine using purely the power of C++ in OpenGL.
- This application can generate chunks of natural blocks like grass, stone, vegetation like trees, grass, flowers, and ores like iron and diamond.
- Caves are also present, generated by precomputted noise maps and distinguishing by height levels all the way to the base level distinguished by an indestructible bedrock
- In addition to these, phong lighting(using directional and point lights) and directional shadow mapping are performed using the OpenGL API to add more details to the world.
- Efficient face, chunk and block culling was also performed in order to maximize the speed of chunk generation and reduce lag.
